StudioFlow Enable

StudioFlow Enable is a compact Adobe Premiere Pro plugin for batch-enabling and disabling supported timeline items.

System requirements

  • Adobe Premiere Pro with UXP plugin support
  • A compatible version of macOS or Windows supported by Adobe Premiere Pro
  • Adobe Creative Cloud Desktop for Marketplace installation

How to open the plugin

Window → UXP Plugins → StudioFlow Enable

Available controls

All

Enables or disables all supported video and audio timeline items.

Video

Enables or disables supported video clips.

Audio

Enables or disables supported audio clips.

Adjustment Layers

Enables or disables adjustment layers.

Undoing an operation

StudioFlow Enable does not include a separate Undo button.

Use Premiere Pro’s native Undo command:

  • macOS: Command + Z
  • Windows: Control + Z

Each completed batch operation is designed to behave as one undoable transaction.

Troubleshooting

The plugin cannot find an active sequence

Open a sequence in the Premiere Pro Timeline panel and try again.

A button does not change any clips

Make sure the active sequence contains timeline items of the selected type.

Graphics are not available as a separate category

The current Premiere Pro UXP API does not provide a reliable supported method for identifying every existing graphics item. StudioFlow Enable therefore does not use filename or metadata heuristics.

The plugin does not appear in Premiere Pro

Confirm that:

  • the plugin was installed through Adobe Creative Cloud,
  • the installed Premiere Pro version supports UXP plugins,
  • Premiere Pro was restarted after installation.
